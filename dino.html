The first stage of segmentation: each object is found by a free-text prompt passed to Grounding DINO, which returns boxes above a 0.30 score. Nothing downstream checks that a prompt matched exactly one thing. These boxes are not saved by the pipeline — it keeps only the final masks — so they were recaptured by re-running the model on sampled frames with each recording's own compiled config. Click a box for its prompt and score. Watch for frames where "a cup ." returns more than one box: every one of them is merged into the same mask_obj1.png. Boxes come from IDEA-Research/grounding-dino-tiny at box_threshold 0.3, re-run on 8 frames per recording using the compiled preprocess/cfg/DINOSAM.yaml each recording was actually built with. Coordinates are pixels in the displayed (downscaled) frame; the source frames are 1280×1920. The prompts are the task file's own: obj1 "a cup .", obj2 "a plate .", arm "human arms . human hands .". Each must end in a space and a period — that is Grounding DINO's phrase separator. There is no negative prompting and no mutual exclusion between obj1 and obj2, which is why one prompt can claim the other's object. See also SAM Masks · Sparse Points.
