Pipeline

How it works

  1. Depth: MoGe-2 predicts metric depth from each rectified egocentric RGB frame.
  2. Metric scale correction: monocular "metric" depth still drifts per frame, so each frame's depth is rescaled by the median ratio between predicted depth and known 3D anchors projected into the frame — the MPS semidense SLAM points and the triangulated object keypoints. Near-field anchors (z < 1.5 m) are preferred, so the fit is set by the workspace rather than the far walls. Typical scale on demo 000: 0.821 ± 0.039.
  3. Cleanup: the human arm is removed with the segmentation mask; points are cropped to a 0.6 m sphere around the static anchor object (the workspace).
  4. Sampling: farthest-point sampling keeps 1024 scene points; they are appended to the 128 V1 entity points with a zero entity one-hot, leaving the feature schema unchanged.

Built with preprocess/PointCloudGen.py --dense (writes per-frame pcd_dense.npz), MoGe-2 for depth, and the same viewer pair extract_pcd_seq.py + make_pcd_viewer.py. At robot inference the scene points come from the RealSense depth stream instead of MoGe — same contract, real depth.
