Coordinates are centimetres in the recording's MPS closed-loop world frame — the same frame the policy's reference transform is built from. Object points are the 20 equidistant inner-contour samples of that frame's mask (the identical sampler that produced the original keypoints), lifted through a per-frame metric depth scale. They are re-sampled independently every frame, so a given index is not a tracked correspondence across time — only the set is meaningful. Frames whose mask fails the quality gate hold the last good points rather than snapping back to the static pool; those show as held in the inspector. Against independent MPS semidense points this lift is closer to truth than the legacy triangulated pool on both objects (cup +14.3 mm vs +17.7 mm, plate −22.7 mm vs +24.6 mm). The three hand channels are the extractor's hand_mode options, verified bit-identical to its own output. Built by preprocess/SparsePointsGen.py. See also Dynamic Scenes.
