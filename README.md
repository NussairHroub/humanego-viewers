# cup_plate_02 — 3D camera-pose viewer

Interactive 3D visualization of 64 Aria cup_plate_02 demos: the fused semidense room
point cloud plus each demo's registered camera frustums and head trajectory.

**View it:** open `index.html` in any browser, or the GitHub Pages link for this repo.
Drag to rotate, scroll to zoom, shift-drag to pan; use the slider to step through demos.

Self-contained (all geometry embedded); renders with WebGL, falling back to Canvas-2D
where WebGL is unavailable.
