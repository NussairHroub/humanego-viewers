Closed-loop runs on the physical ALOHA rig (vx300s right arm, RealSense D455) — the same cup → plate task the policies were trained on from human egocentric video, with no robot demonstrations. Each tile is the plain camera view of one rollout — no overlays. Frames are saved once per policy step, so playback runs ~25× real time; the header in each video carries the true elapsed seconds. Use the show menu to view one group at a time. For the same runs with detections, policy input and gripper overlay, use the four-panel view.

Read the done-probability before drawing conclusions. Across all 21 runs the policy's termination head never exceeded 0.05 against a 0.80 threshold — no episode ended because the policy judged the task complete; each was stopped by the operator. Whether the motion itself succeeded is a separate judgement, and one these videos are meant to support.

Orientation — cup on its side

Baseline policy, but the cup lies on its side instead of standing upright, in two orientations roughly 180° apart. Every collected demonstration has the cup upright, so this is a configuration the policy never saw in training. Also on its own page: the Orientation deck, where each run can be switched to the four-panel view.
