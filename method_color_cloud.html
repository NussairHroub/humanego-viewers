True-color semidense cloud

The same room cloud and camera poses as the plain cup_plate_02 viewer, but each SLAM point carries the color it actually has in the video.

open the viewer →

How the points get their color

  1. Take the fused semidense cloud in the viewer frame (the reference demo's MPS world).
  2. For every rectified RGB frame of the reference demo, project all points using that frame's intrinsics K and camera-to-world pose; keep samples that land inside the image with positive depth.
  3. Assign each point the median RGB over all frames where it was sampled. About 72% of the points are seen at least once; the rest stay neutral grey.
  4. A mild display contrast stretch is applied at bake time so the cloud reads well against the page — colors are for viewing, not radiometry.

What you can see

The black table, the white plate on it, and the cabinets become directly recognizable, which makes it much easier to relate the camera frustums to the physical room than with the plain grey cloud. Colored points render slightly larger than grey ones so the colored structure dominates visually.

Built with color_cloud.py (two stages: sample projects points into the reference demo's rgb.png / aria_cam_rgb.json frames and takes per-point median color; fuse rebuilds the cloud npz) and make_web_viewer.py --cloud, which renders per-point colors in both the WebGL and Canvas-2D paths.
